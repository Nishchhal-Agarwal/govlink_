🏛️ GovLink
An AI-Powered Welfare Scheme & Tax Benefit Recommender for Indian Citizens
GovLink is a smart web platform that helps Indian citizens discover government welfare schemes and estimate tax liabilities — personalized using AI. It aims to bridge the gap between citizens and available public benefits using modern technology and data science.

Features:
🇮🇳 Scheme Finder: Personalized welfare scheme recommendations based on age, income, job, region, caste, and gender.

📊 Tax Calculator: Instant income tax estimate based on the latest slabs.

🔐 User Login/Signup: Secure access to personalized services.

☁️ Firebase Integration: Real-time data storage and authentication.

⚙️ Modern UI/UX: Built with React, Tailwind CSS, Framer Motion for smooth experience.

💡 Example Use Case:
You are a 24-year-old woman from rural Uttar Pradesh with ₹1.8 lakh annual income. You login to GovLink → Click “Find Schemes” → The platform automatically shows you schemes like PM Awas Yojana, Ujjwala Yojana, and Startup India (Women Entrepreneurs) — curated just for you.

🚀 Vision:
To democratize access to government benefits through technology, especially for those who may not be aware of what they’re eligible for.
